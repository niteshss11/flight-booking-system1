# Flight Ticket Booking System

## Project Description
A simple Java-based Flight Ticket Booking System that allows users to log in, check available seats, book tickets, and cancel tickets using a menu-driven program.

## Features
- User Login Validation
- Check Available Seats
- Book Flight Tickets
- Cancel Flight Tickets
- Exception Handling
- Menu-Driven Interface

## Concepts Used
- Java OOP
- Classes and Objects
- Encapsulation
- Exception Handling
- Custom Exceptions
- Scanner Class
- Switch Case
- Do-While Loop

## Custom Exceptions
- `InvalidUserException` – Handles invalid username.
- `NoSeatsException` – Handles insufficient seat availability.

## Technologies Used
- Java
- JDK
- VS Code / IntelliJ IDEA

## Default Details
- Flight Name: Indigo
- Username: `user`
- Initial Available Seats: 10

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Compile the Java file:

```bash
javac Main.java
```

4. Run the program:

```bash
java Main
```
